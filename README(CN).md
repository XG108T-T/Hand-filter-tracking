# 🖐️ Finger Magic - 实时手指特效滤镜

基于 MediaPipe 和 OpenCV 的实时手指交互特效工具。通过双手手指拉出四边形，框内自动应用动态滤镜特效。

## ✨ 特性
- 实时手部追踪（MediaPipe）
- 2-5 指自由切换
- 多种滤镜风格（漫画、反转、像素、热感）
- 动态特效组合（故障、数据流、内存泄漏等）
- 简单/丰富模式切换
- 黑白反转
- 纯框内特效，不遮挡背景

## 🎮 快捷键
- `2-5`：选择手指数量
- `Q/W/E/R`：切换全局基调
- `1`：切换简单/丰富模式
- `空格`：黑白反转
- `ESC`：退出

## 📦 依赖
- Python 3.8+
- OpenCV
- MediaPipe
- NumPy

## 🚀 快速开始（新手指南）

### 第一步：安装 Python（如果还没有）
本程序需要 Python 环境。如果你还没有安装 Python：

1. 访问 [python.org/downloads](https://www.python.org/downloads/)
2. 下载 Python 3.8 或更高版本的安装包（选择对应你系统的版本）
3. 运行安装包，**务必勾选“Add Python to PATH”**（添加到环境变量）
4. 一路“下一步”完成安装

> 💡 **验证安装**：打开命令提示符（CMD）或终端，输入 `python --version`，如果显示版本号，说明安装成功。

### 第二步：一键安装依赖
- **Windows 用户**：双击 `setup.bat` 文件
- **Mac/Linux 用户**：打开终端，进入项目文件夹，执行 `bash setup.sh`

脚本会自动安装所有必需的 Python 库。

### 第三步：运行程序
在命令提示符或终端中，进入项目文件夹，执行：
```bash
python FingerMagic_vx.py
